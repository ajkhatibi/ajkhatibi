### Architectural Specialties

- **Offline-First & Local-Database Engines:** Designing fault-tolerant field and enterprise mobile apps using **WatermelonDB (SQLite)** and **React Query (TanStack)** with optimistic UI updates, delta syncing, and automated conflict resolution.
- **Universal Design Systems & Accessibility:** Building token-driven, cross-platform component libraries (**Expo**, **Gluestack UI**, **TypeScript**) enforcing strict **WCAG 2.0/2.1** accessibility standards and 80%+ automated test coverage.
- **Brownfield Migrations & Native Bridges:** Migrating legacy native iOS/Android modules into unified React Native architectures, building **SwiftUI** home-screen widgets, and integrating custom hardware SDKs (**Clover POS**, Bluetooth/telemetry).
- **AI-Augmented Engineering & CI/CD Velocity:** Combining modern AI workflows with strict TypeScript domain modeling, **Jest / React Native Testing Library / Cypress**, and automated **GitHub Actions** pipelines.
